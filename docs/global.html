setCookie(nombre, valor, diaopt) → {void}

Crea o actualiza una cookie. El valor se codifica con encodeURIComponent(). Si se indica un número de días, la fecha de caducidad se calcula con el objeto Date (fecha actual + días) y se añade como atributo "expires" en formato UTC. Si no se indica, la cookie es de sesión (sin "expires" ni "max-age") y se elimina al cerrar el navegador. Se fija path=/ para que la cookie sea accesible desde toda la aplicación.
Parameters:
Name Type Attributes Description
nombre string Nombre de la cookie.
valor string Valor que se va a almacenar.
dia number <optional>
 Días hasta la caducidad. Si se omite, cookie de sesión.
